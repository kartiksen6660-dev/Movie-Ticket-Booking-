About the Project

CineBook is a web-based movie ticket booking project created to demonstrate the practical application of Database Management Systems (DBMS). It provides a website interface where users can explore movie posters and navigate through a movie booking process.

The academic project also covers relational database design, SQL queries, data management and transaction concepts used in booking-related applications.

Project Objectives

  • Understand the role of DBMS in a real-world application.
  • Organize data using relational database tables.
  • Practice SQL commands and database operations.
  • Understand primary keys, foreign keys and relationships.
  • Demonstrate a user-friendly movie booking workflow.

03. Database Design

The following entities represent a possible database structure for a movie ticket booking system. The final schema should match the actual SQL files submitted with the project.

Entity Purpose
Customers Stores customer details.
Movies Stores movie names and related information.
Bookings Stores booking information.
Seats Represents seats and their related information.
Payments Represents payment information, if included.

Database Relationships

  • One customer may make multiple bookings.
  • One movie may be associated with multiple bookings.
  • Bookings may be linked to seat records.
  • Primary keys identify records uniquely.
  • Foreign keys establish relationships between tables.

05. How to Run the Project

A. Website Instructions

  1. Open the CineBook GitHub repository.
  2. Locate the index.html file.
  3. Open the published GitHub Pages website.
  4. Navigate through the available pages and test the links.

B. SQL Instructions

  1. Open a compatible SQL compiler or database system.
  2. Run the database and table creation statements first.
  3. Execute the sample data insertion statements.
  4. Run the SQL queries and review the results.
  5. Test transaction examples in a compatible database.

06. Project Limitations

  • The GitHub Pages website is a static frontend unless connected to a backend service.
  • A live MySQL connection is not provided by GitHub Pages alone.
  • Persistent bookings require a backend and database integration.
  • Real payments and live seat availability are not assumed to be implemented.

07. Learning Outcomes

Through this project, the following learning outcomes are explored:

  • Understanding relational database concepts.
  • Designing database tables and relationships.
  • Using SQL for data retrieval and modification.
  • Understanding transaction management and data integrity.
  • Connecting DBMS concepts to a practical application.
